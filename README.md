# Cocktail Adventures

Two interactive "choose your own adventure" cocktail books, each a single web page you can read on a phone or computer.

## The books

**The Wayfarer's Pour** (`wayfarers-pour.html`)
Travel the world through the origins of spirits. Visit the Scottish Highlands, the Caribbean, England, Jalisco and Italy. Collect passport stamps and ten classic recipes along the way.

**I Feel Like Something** (`feel-like-something.html`)
Start with a mood (whimsical, methodical, adventurous, classic, abrasive or romantic), follow a short story led by a literary character, and land on three cocktails to match.

## View online

Once GitHub Pages is switched on, the books are live at:

`https://JoSo005.github.io/cocktail-adventures/`

## Files

| File | What it is |
|---|---|
| `index.html` | Home page with links to both books |
| `wayfarers-pour.html` | Book 1, origins of spirits |
| `feel-like-something.html` | Book 2, mood to cocktail |

Each book is one self-contained file. There is nothing to install or build.

## Editing

Open a file on GitHub, click the pencil icon, make your change and choose **Commit changes**. The live site updates in about a minute.

## Notes

- Cocktail origin stories are often disputed. Where a story is a legend, the text says so.
- Recipes are classic starting points, not house specifications.
- Please drink responsibly.
